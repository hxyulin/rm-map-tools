# RoboMaster 2027 assets, 15 October 2026

This release contains the official RMUC 2027 V1.0.0, RMUL 2027 3v3/1v1
V1.0.0, and energy-unit source geometry in four workflow-specific archives.

- [CAD STEP, 208.9 MB](https://github.com/hxyulin/rm-map-tools/releases/download/rm2027-assets-20261015/rm2027-cad-step.zip):
  17 source-based assemblies, source hashes, exact placements, and OCCT validation.
- [Optimized GLB, 143.9 MB](https://github.com/hxyulin/rm-map-tools/releases/download/rm2027-assets-20261015/rm2027-glb-optimized.zip):
  component and full-map visuals, separate collision meshes, semantic sidecars,
  and mesh reduction reports.
- [Simulator models, 200.6 MB](https://github.com/hxyulin/rm-map-tools/releases/download/rm2027-assets-20261015/rm2027-simulators.zip):
  SDF, URDF, and USD assemblies with shared STL resources and placement metadata.
- [Viewer models, 186.4 MB](https://github.com/hxyulin/rm-map-tools/releases/download/rm2027-assets-20261015/docs-viewer-models.zip):
  21 source-rest-pose models and a catalog for the existing documentation viewer.

## Source support

All four files parse and split with both source tooling and OCCT read-back
checks. The STEP model now preserves product ownership when Creo references
the same surface body through a property-only representation. Product IDs
disambiguate repeated opaque names, and occurrence-path coverage is checked
before generating a map. RMUL negative-Y-up coordinates are converted to a
right-handed Z-up arena frame. Component geometry retains its source axes;
apply each recorded placement once.

Each archive groups files by source: `rmuc2027`, `rmul2027-3v3`,
`rmul2027-1v1`, and `energy-unit2027`. Extract the CAD and GLB archives into
the same directory to resolve the GLB manifests' optional `cad/` references.
The simulator archive contains a separate `rm_map_equipment` ROS package
for each source; install one package of that name at a time. Simulator
`semantics.json` files retain the arena placements.

## Fidelity and motion

The optimized GLB archive uses locked-border simplification with component
preservation, a 1 mm error setting, and a 2 mm sampled deviation limit with
512 samples per direction. Full maps are recomposed from those components.
These are sampled checks against input tessellation, not certified maximum
CAD errors. Simulator and viewer models retain unsimplified source tessellation.

**Models preserve the 2027 CAD rest pose.** Mechanical joint bindings, travel
limits, actuators, and match controllers are not authored. SDF/URDF/USD
assemblies therefore have fixed single-link geometry. The 2026 joint rigs,
geometry reconstructions, artwork selections, and road grafts are not reused.
The viewer supports orbiting and zooming without movable joint controls.

Validation covers source and package hashes, complete occurrence ownership,
OCCT assembly read-back, mesh bounds, semantic bindings, XML mesh paths, USD
stage opening, viewer decompression checksums, and ZIP integrity. It does not
establish dynamic simulation behavior or competition certification.
