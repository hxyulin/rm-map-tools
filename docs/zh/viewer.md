# 交互模型查看器

[文档](index.md) · [English](../viewer.md)

选择一个机构加载其 CAD 模型，用滑块移动各个可动实体；拖动旋转视角，滚轮缩放。**Focus** 聚焦某关节控制的几何；**Fit view** 显示整个机构。

目录按需加载模型，打开本页不会下载整个场地。网格与关节绑定来自参考资源包。科技核心使用带示意轴承的既有 CAD 展示绑定；其导出的参考模型仍包含固定的关节框架。

在 GitHub 上浏览时，运行[文档网站](site.md)即可使用查看器；目录需要其中说明的生成模型包。通过本地文件控件打开的文件只保留在浏览器中，不会上传。

## 拖动科技核心工具

选择科技核心并点击 **Drag tool**。拖动箭头沿单个世界轴移动，或拖动平面方块在两个轴上移动。手柄起点在工具装配包围盒中心；六关节求解器把该点移向目标并同步滑块。点击 **Stop dragging tool** 隐藏手柄。

这是 CAD 展示绑定上的纯位置逆解。工具姿态可以变化，工具滚转仍由滑块控制。±1.2 弧度（约 ±68.8°）的关节范围是预览保护值，不是实测机械限位；范围外的目标可能无法到达，查看器会报告剩余距离。Reset 恢复静止姿态并使手柄复位，滑块也会使手柄复位。

求解器使用有界迭代和 0.5 毫米位置阈值，可能在局部解停止，尤其在奇异位形附近。没有碰撞规避、标定工具中心点或物理控制器。参考导出仍包含固定关节框架，见[科技核心关节](../technology-core-joints.md)。

## 打开你的导出结果

选择 GLB 文件，或选择包含导出的 URDF/SDF 设备及其网格的文件夹。文件夹内有多个模型时，从模型列表中选择。查看器在所选文件夹内解析相对网格路径和 ROS `package://` 路径；文件缺失或有歧义会报错。

| 输入 | 查看器支持的内容 |
| --- | --- |
| GLB | 网格、材质、轨道控制，以及内嵌动画片段的时间轴 |
| URDF | 可视网格，fixed/revolute/continuous/prismatic 关节、限位与关节滑块 |
| SDF | `export_articulated.py` 写出的单模型设备子集，包括模型内连杆姿态和子坐标系关节框架 |

内置目录为每个模型提供语义绑定。对任意本地 GLB，请先把参考资源包导出为 URDF 或 SDF 以暴露关节；本地文件加载不会自动解析单独的 `articulation.json`。

本查看器不支持 SDF world、嵌套模型、插件、任意框架图和多轴关节；不支持的 SDF 构造会被拒绝，而不会以错误变换静默显示。完整 SDF 场景请使用目标仿真器检查；碰撞仿真与控制器不在查看器范围内。

滑块关节使用米，转动关节使用弧度。continuous 关节每个方向显示一整圈。Reset 将所有关节和动画归零；Fit view 按当前姿态取景。
