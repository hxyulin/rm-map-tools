# Releases and downloads

Use one release per asset revision, with separate archives for each workflow. STEP, GLB, simulator models, and the documentation viewer share a release tag so their provenance and differences can be reviewed together. A new release is appropriate when the asset revision changes, rather than simply because another file format is added.

## RoboMaster 2027

The [15 October 2026 release](releases/2026-10-15.md) includes RMUC 2027,
RMUL 2027 3v3/1v1, and the energy unit: CAD STEP, optimized GLB, SDF/URDF/USD,
and a 21-model viewer catalog. These are source-rest-pose models; mechanical
joint controls are not yet bound.

[Download the 2027 assets](https://github.com/hxyulin/rm-map-tools/releases/tag/rm2027-assets-20261015)
or follow the [2027 build workflow](rm2027.md).

## RMUC 2026

| Download | Use |
| --- | --- |
| `rmuc2026-cad-step.zip` | Editable source-based STEP assemblies and placement metadata |
| `rmuc2026-glb-optimized.zip` | Optimized field visuals, colliders, textures, and manifests |
| `rmuc2026-simulators.zip` | Individual equipment in SDF, URDF, and USD, with shared mesh resources |
| `docs-viewer-models.zip` | The five interactive documentation models and joint catalog |
| `SHA256SUMS.txt` | Archive integrity checks |
| `validation-summary.json` | Packaged sources and validation scope |

Download only the archives you need. Simulator formats share a ZIP because SDF and URDF share the same STL resources. The source-code archives generated by GitHub contain tooling, not the model downloads above.

See the [11 September 2026 release notes](releases/2026-09-11.md) and the [latest release](https://github.com/hxyulin/rm-map-tools/releases/latest).

The [2027 asset build workflow](rm2027.md) generates equivalent archive categories
for RMUC, RMUL 3v3/1v1, and the energy unit. Its models preserve the 2027 CAD rest
pose; the 2026 mechanical joint bindings are not reused.

After extracting, retain each package's directory structure and manifests. A model in the optimized GLB package can differ from the unsimplified reference used for joint export; matching release tags do not imply identical tessellation across formats. CAD source geometry and reconstructed display geometry are also separate. The release notes identify these differences.
